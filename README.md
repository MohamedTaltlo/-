# مزرعتي — Mazraati

تطبيق Android عربي بواجهة RTL لإدارة حيوانات الماعز والأعلاف وتسجيل الحساب الغذائي محلياً. لا يحتاج التطبيق إلى حساب أو اتصال بالشبكة لحساب الحصص أو حفظ البيانات.

> **تنبيه سلامة:** الحسابات إرشادية وليست توصيات لعليقة آمنة. يجب الرجوع إلى طبيب بيطري أو اختصاصي تغذية مجترات محلي قبل الاستخدام الفعلي. لن يفترض التطبيق تركيبة علف أو احتياجاً غذائياً غير مدخل.

## المصدر

المستودع المقدم كان فارغاً في 19 نوفمبر 2026. هذه قاعدة مشروع جديدة مستقلة، **وليست استعادة لحزمة v6 غير المتاحة**. لا تستورد قاعدة بيانات قديمة فوق هذا المشروع دون كتابة migration موثقة واختبارها.

## ما يعمل

- تسجيل الحيوانات مع الوزن والحالة والجنس وبيانات الحمل أو الحليب وBCS (مقياس 1–5).
- تخزين الأعلاف والتصنيف والمخزون والسعر والتحليل الغذائي ومصدره وتاريخه.
- حساب مجموع المواد الجافة والطاقة الأيضية ME (ميغاجول) والبروتين الخام وNDF من كميات as-fed مع قواعد منع للمعلومات غير المتاحة.
- إدخال نطاقات الاحتياجات من المستخدم أو مراجع يسجل بياناتها المستخدم، وحصرها بحالة الحيوان.
- رصد تجاوز الحد اليومي الذي يدخله المستخدم والمخزون الذي سجله.
- عرض القيم الناقصة دون ملئها بأرقام افتراضية، والتمييز بين وزن العلف كما يُقدّم والمادة الجافة.
- حفظ الحصص وملخصاتها في SQLite ونسخ تقرير نصي محلي.
- اختبارات حسابية باستخدام **بيانات مصطنعة للاختبار فقط**.

## ما لم يكتمل

لا يوجد موازن آلي متعدد القيود، ولا قاعدة علمية مضمّنة للاحتياجات، ولا حساب للماء والمعادن، ولا نسخ احتياطي أو استيراد v6 أو مقارنة حصتين أو اختبارات أجهزة فعلية بعد. الأسعار بعملة الإدخال دون تحويل.

## التنزيل والبناء

عند اكتمال نجاح GitHub Actions: [تنزيل أحدث APK](https://github.com/MohamedTaltlo/-/releases/download/latest/mazraati.apk).
لمتابعة البناء: [Actions](https://github.com/MohamedTaltlo/-/actions/workflows/build-apk.yml).

محلياً عند توفر Flutter وAndroid SDK:

~~~bash
flutter create --project-name mazraati --org online.mtradius --platforms android .
flutter pub get
flutter test
flutter build apk --release
~~~

يُنشئ سير العمل ملفات Android القياسية باستخدام Flutter SDK قبل البناء، لذا لا حاجة إلى Android Studio على هاتف المستخدم.

## الخصوصية

المعلومات تُحفظ داخل قاعدة بيانات على الجهاز. لا يستخدم التطبيق API أو تسجيل دخول أو إنترنت. **إزالة التطبيق قد تزيل كل السجلات** ما لم يكن لديك نسخة خارجية (النسخ الاحتياطي لم يُنفذ بعد).
